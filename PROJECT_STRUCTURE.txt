DNS Collector - Project Structure
==================================

Repository: git@github.com:grom-alex/dns-collector.git
Stack: Go 1.24 + PostgreSQL 16 + Vue 3 + Docker Compose
Top-level: two Go modules (dns-collector, web-api), shared PostgreSQL.

Runtime / not in git
====================

- PostgreSQL data volume (Docker) or database cluster.
- Docker images (registry.gromas.ru/apps/dns-collector/*).
- .gocache/, .gomodcache/ if used for local builds.
- Build artifacts: bin/, build/, coverage.out, coverage.html.
- Local .env files (never commit).

Key Data Flows
==============

1. Unbound/pfSense -> UDP JSON :5353 -> dns-collector.
2. dns-collector -> PostgreSQL: domain_stat (each packet), domain/ip.
3. Resolver -> DNS -> PostgreSQL: ip upsert + domain counters.
4. Cleanup -> PostgreSQL: retention deletes (stats/ip/domain).
5. web-api -> PostgreSQL: read queries, Excel, export lists.
6. Prometheus <- dns-collector:9090/metrics and web-api:8080/metrics.

Useful Commands
===============

Build:        make build
Test:         make test
Race tests:   cd dns-collector && go test -race ./internal/...
Docker:       docker compose up -d
Logs:         docker compose logs -f
DB shell:     docker compose exec -T postgres psql -U dns_collector -d dns_collector
Backup:       docker compose exec -T postgres pg_dump -U dns_collector -Fc dns_collector > backup.dump
Plan:         docs/OPTIMIZATION_PLAN.md
